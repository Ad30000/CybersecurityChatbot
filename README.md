# 🔐 Cybersecurity Awareness Bot

A C# application designed to promote cybersecurity awareness through an interactive chatbot, educational quizzes, and activity logging.

## 📌 Overview

The Cybersecurity Awareness Bot is a software development project created as part of the PROG6221 Programming 2A Portfolio of Evidence (POE).

The application aims to make cybersecurity education more accessible by providing users with an interactive chatbot experience, opportunities to test their cybersecurity knowledge through quizzes, and activity logging to record relevant application activities.

The project was developed incrementally using Git and GitHub for version control, with version tags documenting milestones throughout development.

## ✨ Features

### 💬 Cybersecurity Chatbot
- Provides an interactive interface for cybersecurity-related conversations.
- Uses programmed response logic to respond to user input.
- Helps users engage with cybersecurity awareness topics.

### 📝 Cybersecurity Quizzes
- Allows users to test their cybersecurity knowledge.
- Provides an interactive learning experience.
- Encourages users to improve their understanding of online safety and cybersecurity practices.

### 📋 Activity Logging
- Includes activity logging functionality to record relevant application activities.
- Supports tracking interactions and events handled by the application.

### 🛠️ Incremental Development
- Uses Git version control to track changes.
- Includes version tags representing development milestones.
- Demonstrates incremental improvements to the source code.

## 🧰 Technology Stack

- **C#** — application development.
- **Git** — version control.
- **GitHub** — repository hosting and source code management.

## 🚀 Getting Started

### Prerequisites

- A Windows environment if the application uses Windows-specific desktop components.
- Visual Studio with the appropriate C# development workload.
- The .NET SDK version required by the project.
- Git, if you want to clone the repository.

### Installation

Clone the repository:

```bash
git clone https://github.com/VCDN-2025/prog6221-poe-ad70000.git
```

Navigate to the project directory:

```bash
cd prog6221-poe-ad70000
```

Open the solution file in Visual Studio, restore the required dependencies, and build the application.

**Note:** The exact solution filename and run command depend on the current repository structure.
